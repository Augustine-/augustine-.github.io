# portfolio

My interactive business card. Flip it around, check out some of the things I've made.

The card is real: a dark room, one card, and your cursor is the light. Three small
hand-written WebGL2 passes (each face, and the tablecloth) light bone paper, letterpress
type and a raised lacquered-black name from wherever the cursor is. The DOM text on top
is transparent but real, so links, focus and screen readers all work; without WebGL the
same page renders as a plain paper card. No dependencies.
